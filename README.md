## 🇮🇷 درباره پروژه

این سامانه یک **محیط آموزشی تعاملی کامل** برای درس **آمار و احتمال مهندسی** است که با تمرکز روی یادگیری عمیق طراحی شده:

- توضیح کامل هر مفهوم همراه با فرمول
- مثال‌های حل‌شده عددی
- شبیه‌سازهای زنده (بسیاری از آن‌ها سه‌بعدی و قابل چرخش)
- پنل «حل گام‌به‌گام» که اعداد واقعی را داخل فرمول جایگذاری می‌کند
- کیبورد هوشمند ریاضی برای نوشتن هر فرمولی
- آمار توصیفی جامع + جدول فراوانی + ساقه-برگ + نمودارهای مختلف

## 🛠️ ابزارهای موجود

### 🔔 توزیع‌های احتمال
- نرمال (۳D) • نرمال دومتغیره (۳D)
- دوجمله‌ای • پواسون • هندسی • نمایی • یکنواخت
- توزیع t و کای‌دو

### 🎲 شبیه‌سازها
- پرتاب تاس سه‌بعدی • پرتاب سکه سه‌بعدی
- مونت‌کارلو • قضیه حد مرکزی (CLT)

### 📈 داده و رگرسیون
- آمار توصیفی جامع (جدول فراوانی + ساقه-برگ)
- هیستوگرام • نمودار جعبه‌ای • رگرسیون خطی • QQ-plot

### 🧪 آمار استنباطی
- فاصله اطمینان (Z و t)
- آزمون فرض Z

### 🧮 ماشین‌حساب
- ویرایشگر فرمول آزاد
- محاسبه‌گر احتمال نرمال و دوجمله‌ای
- ترکیبیات (فاکتوریل، جایگشت، ترکیب)
